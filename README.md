## Purpose of the Project
I analyzed restaurant sales data using SQL to help a business decide which menu items to keep, improve, or remove based on customer purchasing behavior.

## Data Source: Maven Analytics

## Tools & Technologies
- SQL
- Microsoft SQL Server Management Studio (MSSMS)

## Data includes:
- Orders
- Menu items
- Prices

## Data Quality Checks
- Identified and checked for outliers
- Validated data consistency
- Ensured clean data before analysis

## Key Analytical Questions
- Which menu items generate the most revenue?
- Which items have low sales or poor performance?
- What cuisine types do customers prefer?
- Are there noticeable spending patterns?
